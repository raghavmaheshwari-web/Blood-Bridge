# Blood Bridge 🩸

A desktop Blood Donor Registration and Search System built with Python and Tkinter.

## Features
- **Donor Registration & Editing**: Register voluntary blood donors with real-time validation (age 18–65, weight, contact info).
- **Emergency Compatibility Matching**: Match donors based on exact blood group or full recipient compatibility (e.g., $O^-$ universal donor).
- **Search & Filters**: Search by blood group, city/location, keywords, or filter by active eligibility ($\ge 90$ day cooldown).
- **Donor Management**: Record donations, view donor profiles, and export records to CSV.
- **Compatibility Reference Matrix**: Built-in ABO and Rh blood compatibility guide.

## Requirements
- Python 3.x (Tkinter is included with standard Python installations)

## Running the Application
```bash
python3 app.py
```
